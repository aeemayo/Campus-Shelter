# Campus Shelter 🏠

Welcome to **Campus Shelter**! This project is a modern, responsive landing page designed to help students find their perfect accommodation with ease. It's built with love using the latest web technologies to ensure a smooth and engaging user experience.

## What's Inside? 

We've crafted a set of components that work together to create a compelling landing page:

- **Hero Section**: A catchy introduction to grab attention immediately.
- **Features**: Highlights the key benefits of using our platform.
- **Popular Locations**: Showcases the best housing spots around campus.
- **How It Works**: A simple, step-by-step guide to getting settled.
- **Testimonials**: Social proof from happy students who found their homes.
- **Call to Action**: Encourages users to sign up or start their search.

## Tech Stack 

We're using a robust and modern stack:

- **Framework**: [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) (for solid type safety).
- **Build Tool**: [Vite](https://vitejs.dev/) (It's strictly fast!).
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (Utility-first goodness).
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/) (Beautiful, accessible, and customizable components).
- **State Management**: [TanStack Query](https://tanstack.com/query/latest) (For efficient data fetching).
- **Testing**: [Vitest](https://vitest.dev/) (For peace of mind).

## Getting Started 

Want to run this locally? It's easy easy.

### Prerequisites

Make sure you have Node.js installed. We also noticed a `bun.lockb` file, so if you're a fan of [Bun](https://bun.sh/), you're good to go!

### Installation

1.  **Clone the repository:**
    ```bash
    git clone <your-repo-url>
    cd Campus-Shelter
    ```

2.  **Install dependencies:**
    
    Using npm:
    ```bash
    npm install
    ```
    
    Or if you prefer Bun:
    ```bash
    bun install
    ```

3.  **Fire it up!:**
    
    ```bash
    npm run dev
    # or
    bun dev
    ```

    Open your browser and head to the URL shown in your terminal (usually `http://localhost:5173`).
